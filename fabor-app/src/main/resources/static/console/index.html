Dependency rules

          
    
            
  1. *-domain imports no Spring, MyBatis, Kafka or JDBC.
    2. 
            
  2. Adapters → application → domain. Never the reverse.
    3. 
            
  3. A service reaches another service only through its *-api module. No shared tables.
    4. 
            
  4. engines/* are pure: no clock, no I/O, same input gives the same output.
    5. 
            
  5. ledger imports no engine and no product service.
    6. 
            
  6. platform-money bans float and double.
    7. 
            
  7. Database-vendor SQL lives only in *-adapter-persistence, under postgresql/ and oracle/.
    8. 
          

          
Enforced by ArchUnit tests and the Maven Enforcer plugin in every build.

          Asset finance · hire purchase and leasing
          
Fleet and floor plan

          
Fleet: one master agreement per business customer, with a separate hire-purchase schedule for each batch of vehicles. Floor plan: a revolving line for a dealer, drawn vehicle by vehicle and repaid when each one is sold.

How fleet works in the core

            
    
              
  • The master agreement is a parent arrangement; each schedule is a child with its own rate, term, VAT and EIR.
    • 
              
  • Each vehicle has its own asset record and title, so one truck can be paid off, substituted or repossessed alone.
    • 
              
  • Billing is consolidated: one invoice and one payment, allocated across schedules by the waterfall.
    • 
              
  • Cross-default: if any schedule reaches 90 days past due, every schedule moves to TFRS 9 stage 3.
    • 
              
  • Each call-off uses the master facility in the limit tree, so the limit check is atomic.
