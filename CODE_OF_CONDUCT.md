# Code of conduct

Fabor OS adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct for all project spaces: repositories, issues, discussions, chat and events.

In short: be respectful, assume good intent, welcome newcomers, and keep criticism about the work, not the person. Harassment and discrimination are not tolerated.

Report concerns to **conduct@fabor.example** (placeholder: replace before publishing). Reports are handled confidentially by maintainers who are not involved in the matter.
