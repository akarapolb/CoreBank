From → toMechanismWhy

Dependency rules

          
    
            
  1. *-domain imports no Spring, MyBatis, Kafka or JDBC.
    2. 
            
  2. Adapters → application → domain. Never the reverse.
    3. 
            
  3. A service reaches another service only through its *-api module. No shared tables.
    4. 
            
  4. engines/* are pure: no clock, no I/O, same input gives the same output.
    5. 
            
  5. ledger imports no engine and no product service.
    6. 
            
  6. platform-money bans float and double.
    7. 
            
  7. Database-vendor SQL lives only in *-adapter-persistence, under postgresql/ and oracle/.
    8. 
          

          
Enforced by ArchUnit tests and the Maven Enforcer plugin in every build.
